Process Management を読む。

[ps Command in Linux
](https://www.geeksforgeeks.org/linux-unix/ps-command-in-linux-with-examples/)

プロセスの議論だから当然 ps(1) から始める。オプションは `-` から始めたり始めな
かったりする印象があったが、`man 1 ps` によると UNIX 系か BSD 系かの違いから来る
ことがわかった。この説明では `aux` が BSD 式だ。
* `ps ... | grep progname` ではなく `ps -C progname ...`
* グループ周りのオプション名にクセがある。
* pgrep(1) は PID しか出力しない。場合により有用。

[top Command in Linux
](https://www.geeksforgeeks.org/linux-unix/top-command-in-linux-with-examples/)
これは読んだか。
* ここで言うオプション `-M` は私の環境では `-E` か `-e` かその両方。
* コピー＆ペーストするときは `-b -n1` が便利。
* ps(1) の結果を [fzf] にパイプするプログラムを誰も書かないなと思っていた。
  その理由は top(1) に対話的操作機能があるからだろうか。

[htop Command in Linux
](https://www.geeksforgeeks.org/linux-unix/htop-command-in-linux-with-examples/)
も読む。htop(1) は top(1) の改良版？

[kill Command in Linux
](https://www.geeksforgeeks.org/linux-unix/kill-command-in-linux-with-examples/)
この記事は既読か。プロセスを直接操作する命令は `kill` くらいしかない。

[Nice and Renice Command in Linux
](https://www.geeksforgeeks.org/linux-unix/nice-and-renice-command-in-linux-with-examples/)
nice(1) は（実行順序や頃合の）優先度を指定してプロセスを稼動し、renice(1) は稼働
中プロセスの優先度を変える。
* 値が小さいほど優先度が高い。負の値すらある。
