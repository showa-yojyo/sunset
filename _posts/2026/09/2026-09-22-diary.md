[Tar Command in Linux
](https://www.geeksforgeeks.org/linux-unix/tar-command-linux-examples/) を読む。
* `c` が固める。`x` が解く。
* `v` は verbose だから不可欠というわけではない。
* `f` はどちら方向でも指定必須。
* `z`: gzip を意味する。どちら方向でも指定必須。拡張子から自動で判定とかはない。
* `j`: bzip2 を意味する。圧縮率は gzip に優り、処理時間は劣る。
* 圧縮ファイルから個別ファイルを取り出せる。
* `r` で圧縮ファイルの中身を更新？することができる？

[Gzip Command in Linux
](https://www.geeksforgeeks.org/linux-unix/gzip-command-linux/) を読んで gzip(1)
単品を習う。
* `gzip file1 file2` は `file1.gz` と `file2.gz` に変換する。

[gunzip Command in Linux with Examples
](https://www.geeksforgeeks.org/linux-unix/gunzip-command-in-linux-with-examples/) 
を読む。
* `-r` で再帰的に解く。
* `-t` で無傷かどうかを試す。
* `-l` で圧縮具合を示す。
* `-n`/`-N` でタイムスタンプを軽視したり保存したりする。

[ZIP command in Linux
](https://www.geeksforgeeks.org/linux-unix/zip-command-in-linux-with-examples/)
を読む。
* `zip a.zip file1 file2` は `a.zip` が `file1` と `file2` を含む。
* 圧縮ファイルからファイルを追加削除更新できる。
