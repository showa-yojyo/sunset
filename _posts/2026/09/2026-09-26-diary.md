Bash 補完仕様の実例を探す。簡単なものを欲しい。Python 関連の補完をし損ねていたこ
とに気づく。`.bashrc` に次のような処理（一部簡略化）を入れている。しかし、よく考
えたら Python のそれ専用の仮想環境を activate していなければ発動しないのだった：

```bash
command -v pipenv && eval "$(_PIPENV_COMPLETE=bash_source pipenv)"
command -v hatch && eval "$(_HATCH_COMPLETE=bash_source hatch)"
command -v ruff && eval "$(ruff generate-shell-completion bash)"
```

後で修正しておく。

Homebrew の初期化コードも異常だった。本題でないものを修正するのに時間を費やして
しまう。しかし、これをやった甲斐があり、モダンなパッケージの `complete -F` 関数
コードをたくさん発見する。応用しやすいものを選り分ける。
