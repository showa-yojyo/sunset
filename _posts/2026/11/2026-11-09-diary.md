Micromamba 環境が邪魔になるおそれがあるが [uv] の実践に入る。

* Homebrew で本体をインストールする。Bash 自動補完も同時にインストールされる。
  * `uv generate-shell-completion bash` しなくても補完が効くようだ。`uxv` も。
  * `uv 0.13.7 (Homebrew 2026-11-03 x86_64-unknown-linux-gnu)`
  * `$XDG_DATA_HOME/uv/` にファイルが置かれることになる。
* 命令を試す
  * `uv python list`: 3.14 周りは Ubuntu のものを転用するらしい。
  * `uv python uninstall` で Ubuntu のものを捨てることはできない。
  * `uv python install` が Python 3.15 をインストールし始める。
    * 私の `bin` ディレクトリーに `python3.15` が安置される。

こんな長い命令行を毎回入力する必要があるわけではない。この依存情報をコメントとし
てスクリプトに埋め込むことが可能だ：

```console
$ uv add --script mjnet-scraper.py click pyyaml scrapy
Resolved 50 packages in 212ms
$ head mjnet-scraper.py
#!/usr/bin/env python
# /// script
# requires-python = ">=3.15"
# dependencies = [
#     "click>=8.5.1",
#     "pyyaml>=6.0.3",
#     "scrapy>=2.20.0",
# ]
# ///
```

これにより、次回以降の実行命令行は `uv run --script mjnet-scraper.py` で十分とな
る。依存パッケージを更新する手順はいつか調べる。

手許スクリプトに対する `uv add --script` 作業をしばらく続けるか。ついでに Python
3.14 以降では `from __futures__ import annotations` を削れる。
