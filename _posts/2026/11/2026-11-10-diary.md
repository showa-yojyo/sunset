サードパーティー製から CLI 形式で与えられている Python プログラムについては明
示的なインストール指示なしで実行可能。例えば：

```bash
uvx ruff check myscript.py
```

ということは、yt-dlp もこの方式でいけることになる。オプションを増やしてこうだ：

```bash
uvx --pre --from "yt-dlp[default]" yt-dlp ...
```

これがあるのなら Micromamba で yt-dlp を使うためだけの仮想環境は廃止したい。

命令 `uv tool install` を使う場合は、こんな感じになる：

* `~/.local/share/uv/tools/` に対象パッケージをインストール
* `~/.local/bin/` に CLI へのシンボリックリンクを追加

次に `uv init` を習う。パッケージ管理の次は何管理だ？
