自作 Python スクリプトのサードパーティーモジュール依存関係をファイルに埋め込むの
を今片付ける。[uv] のおかげで方針が定まる。問題になりそうなのはスクリプトを呼び
出すたびに `uv run --script` を打鍵するのが面倒だということか。いや、仮想環境の
指定と手間は変わらない。だからこれでいい。実行頻度の高いものだけ `alias` をする
とかでしのげる。

```bash
uv run --with package0 --with package1
uv add --script ./myscript package0 package1
uv run --script ./myscript --version
```

上記をよそのモジュールを `import` している Python スクリプト全てに行う。

[読書ノート][note]の環境を [uv] で管理するように刷新し始める。ついでに Sphinx な
どのバージョンを上げようとしたが、某プラグインの兼ね合いが悪く見合わせる。

`uv init --no-packages` が生成する `pyproject.toml` の内容を `Pipfile` を参考に
書き換える。これで `sphinx-build` を走らせるジョブは通じるようになる。

さらに GitHub Actions のプロジェクト管理プログラムをも [uv] に差し替える。想像以
上にすんなり移行できて素晴らしい。
