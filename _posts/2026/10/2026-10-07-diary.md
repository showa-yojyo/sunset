11:15 復活。

まず `wslvar` が消えた。これは以前 wslu を手動でアンインストールしたから当然。い
い機会だから対処する。`USERPROFILE`, `PROGRAMFILES`, `SYSTEMROOT` の三つだけでい
い。`wslpath` に渡す手間を省ける。`WSLENV` という Windows 側の環境変数を適切に定
義すると、WSL 側でもそれが共有されるらしい。

```pwsh
setx WSLENV "ProgramFiles/pu:SystemRoot/pu:USERPROFILE/pu"
```

大文字小文字を区別することに注意。これでハマった。

13:15 `/etc` 以下の構成ファイル修正完了。タスクスケジューラーに戻る。その過程で
Ruby `bunder` が壊れていることに気づく。Ruby が 3.2 から 3.3 に上がったからだ。
これで解決：

```bash
gem update bundler
```

なお、`bundle update` にオプション `--all` を付けるように注文される。

それにしても Git リポジトリーの中のファイルをスケジューラーで更新しようとなる
と、ブランチかローカルコピーのどちらかは用意しないとおかしい。後者が一般的な実践
だろう。

```bash
/home/linuxbrew/.linuxbrew/opt/micromamba/bin/mamba shell init \
    --shell bash --root-prefix $XDG_DATA_HOME/mamba
```
