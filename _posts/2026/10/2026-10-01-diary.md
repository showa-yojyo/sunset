```bash

```


Windows Task Scheduler をやる。まず、次のタスクを定義できるか試す：

```raw
wsl.exe -d Ubuntu -u root -e sh -c "apt-get update -qq && DEBIAN_FRONTEND=noninteractive apt-get upgrade -qq && apt-get autoremove"
```

手動実行機能があるので大いに利用する。手応えがない。出力を全部殺しているから当然
だ。そこで、Hello world タスクを何か作って Windows 内で動作しているのかを検証す
る。これが盛大にハマる。PowerShell にも Bash と構文が同じ redirection 機能がある
から、それをタスクコマンドとして記述したい。しかし、ファイルが生成されない。

ひとまず `>demo.log 2>&1` のような記述を Task Scheduler の設定 GUI で与えるのを断
念。PowerShell スクリプトファイル内にいったん移す。
