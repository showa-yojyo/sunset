Scrapy 用仮想環境を Micromamba 環境内に復元成功。旧環境で `mamba env export` し
ておいた YAML ファイルをそのまま使えた。Python はバージョンが 3.14 で一致してい
たので話が早い：

```bash
mamba create -f mamba-env-scrapy.yaml
```

この時点でディレクトリー `~/.conda` が生じる。中身は `environments.txt` のみ。

旧 Mamba 環境にはなかった Pipenv 用仮想環境を新規作成する。[読書ノート][note]の
ビルドで今は使っている。

```bash
mamba create -n pipenv python=3.14 pipenv
mamba create -n pipenv python=3.14 hatch
```
